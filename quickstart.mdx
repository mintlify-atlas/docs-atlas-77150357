This guide walks you through installing the `@org-quicko/sheet` package and building a workbook programmatically from scratch. By the end you will have a fully serialized Sheet JSON document logged to your console, complete with a payment table and a settings list.

## Prerequisites

Before you begin, make sure you have the following installed:

- **Node.js** `>= 8.0.0`
- A package manager: **npm**, **yarn**, or **pnpm**
- **TypeScript** (recommended) or a Node.js project configured to run `.ts` files via `ts-node`

## Installation

Install `@org-quicko/sheet` using your preferred package manager. The package bundles `class-transformer`, `class-validator`, and `reflect-metadata` as regular dependencies — all three are installed automatically.

<CodeGroup>

```bash npm
npm install @org-quicko/sheet
```

```bash yarn
yarn add @org-quicko/sheet
```

```bash pnpm
pnpm add @org-quicko/sheet
```

</CodeGroup>

<Note>
  `@org-quicko/sheet` ships `reflect-metadata` as a bundled dependency, so you
  do not need to install it separately. However, the `reflect-metadata` polyfill
  **must be imported once at the very top of your application entry point**
  before any other import that uses decorators. Failing to do so causes decorator
  metadata to be undefined at runtime.
</Note>

## Build Your First Workbook

<Steps>

### Create a Workbook

Import `reflect-metadata` first, then import the Sheet JSON classes and instantiate a `Workbook`. The constructor initializes an empty `sheets` array automatically.

```typescript
import 'reflect-metadata';
import { instanceToPlain } from 'class-transformer';
import { Workbook, Sheet, Table, List, Item } from '@org-quicko/sheet';
import { JSONArray } from '@org-quicko/core';

const workbook = new Workbook();
```

### Add a Sheet

Create a `Sheet` instance and add it to the workbook. Sheets are the direct children of a workbook and act as containers for your table and list blocks.

```typescript
const sheet = new Sheet();
```

### Add a Table Block

A `Table` has a `header` (a `JSONArray` of column name strings) and `rows` (each row is also a `JSONArray` of values). Values are positionally aligned to the header — `rows[n][i]` belongs to `header[i]`. Use `null` for an empty cell.

```typescript
const table = new Table();
table.setHeader(new JSONArray(['reference', 'amount']));
table.addRow(new JSONArray(['PAY-1', 150]));
```

### Add a List Block

A `List` holds key-value pairs as `Item` instances. Each `Item` is constructed with a key string and a value. Lists are ideal for configuration data or document-level metadata.

```typescript
const list = new List();
list.addItem(new Item('currency', 'INR'));
```

### Assemble and Serialize to JSON

Add the blocks to the sheet, add the sheet to the workbook, then call `instanceToPlain` from `class-transformer` with `excludeExtraneousValues: true`. This walks the decorated class hierarchy and produces a plain JavaScript object that you can stringify to JSON.

```typescript
sheet.addBlock(table);
sheet.addBlock(list);
workbook.addSheet(sheet);

const json = instanceToPlain(workbook, { excludeExtraneousValues: true });
console.log(JSON.stringify(json, null, 2));
```

</Steps>

## Complete Example

Here is the full working TypeScript file combining every step above.

```typescript
import 'reflect-metadata';
import { instanceToPlain } from 'class-transformer';
import { Workbook, Sheet, Table, List, Item } from '@org-quicko/sheet';
import { JSONArray } from '@org-quicko/core';

// 1. Create workbook
const workbook = new Workbook();

// 2. Create sheet
const sheet = new Sheet();

// 3. Create table block
const table = new Table();
table.setHeader(new JSONArray(['reference', 'amount']));
table.addRow(new JSONArray(['PAY-1', 150]));

// 4. Create list block
const list = new List();
list.addItem(new Item('currency', 'INR'));

// 5. Assemble
sheet.addBlock(table);
sheet.addBlock(list);
workbook.addSheet(sheet);

// 6. Serialize
const json = instanceToPlain(workbook, { excludeExtraneousValues: true });
console.log(JSON.stringify(json, null, 2));
```

Running this file produces the following output:

```json
{
  "@entity": "workbook",
  "name": "workbook",
  "sheets": [
    {
      "@entity": "sheet",
      "name": "sheet",
      "blocks": [
        {
          "@entity": "table",
          "name": "table",
          "header": ["reference", "amount"],
          "rows": [["PAY-1", 150]]
        },
        {
          "@entity": "list",
          "name": "list",
          "items": [{"currency": "INR"}]
        }
      ]
    }
  ]
}
```

<Note>
  The `name` field on each entity is derived from the class-level
  `@Reflect.metadata('name', ...)` decorator, not from a setter method. The
  base classes (`Workbook`, `Sheet`, `Table`, `List`) always serialize their
  class default names (`"workbook"`, `"sheet"`, `"table"`, `"list"`). To use
  custom names such as `"payment_table"` or `"summary_sheet"`, use the
  [Node.js generator](/generators/nodejs-generator) to generate subclasses
  where each class's metadata is set to the desired name.
</Note>

## Deserializing JSON Back to Classes

To go the other direction — from a plain JSON object back to typed class instances — use `plainToInstance` from `class-transformer`. The `@entity` discriminator field tells the deserializer which class to hydrate for each block.

```typescript
import 'reflect-metadata';
import { plainToInstance } from 'class-transformer';
import { Workbook } from '@org-quicko/sheet';

const raw = JSON.parse(jsonString);
const workbook = plainToInstance(Workbook, raw, { excludeExtraneousValues: true });

const sheet = workbook.getSheet('sheet');
const table = sheet?.getBlock('table');
```

<Tip>
  Use `workbook.getSheet(name)` and `sheet.getBlock(name)` to look up children
  by name (case-insensitive), or pass a numeric index to retrieve by position.
  Both methods are available on `Workbook` and `Sheet` respectively.
</Tip>
