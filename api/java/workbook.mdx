The `Workbook` class is the root container of the Sheet JSON data model. It holds an ordered list of `Sheet` objects and serves as the entry point for building, reading, and manipulating structured spreadsheet data in Java. `Workbook` is a Jackson-annotated bean annotated with `@JsonTypeName("workbook")`, which means it serializes to and deserializes from JSON with a `"name": "workbook"` discriminator property. It extends `BaseObject`, which provides inherited `name`, `entity`, and `metadata` fields. Instances are created with the default no-argument constructor and can be round-tripped through JSON using the bundled `JsonMapper`.

## Installation

Add the following dependency to your `pom.xml`:

```xml
<dependency>
  <groupId>in.org.quicko.sheet</groupId>
  <artifactId>core</artifactId>
  <version>2.0.0</version>
</dependency>
```

## Import

```java
import in.org.quicko.sheet.beans.Workbook;
import in.org.quicko.sheet.beans.Sheet;
import in.org.quicko.sheet.mapper.JsonMapper;
```

## Annotation behavior

`Workbook` carries three Jackson annotations that control its serialization shape:

| Annotation | Value | Effect |
|---|---|---|
| `@JsonTypeName` | `"workbook"` | Sets the type discriminator string written to the `name` property |
| `@JsonTypeInfo` | `Id.NAME` on `"name"` | Reads the `name` property to select the concrete type during deserialization |
| `@JsonIgnoreProperties` | `ignoreUnknown = true` | Unknown JSON fields are silently skipped rather than raising an error |

## Constructor

### `Workbook()`

Creates a new, empty workbook. Internally calls `super("workbook")`, which sets the `@entity` field to `"workbook"` and leaves the `sheets` list uninitialized (lazily allocated on first access).

```java
Workbook workbook = new Workbook();
```

## Methods

### `getSheets()`

Returns the complete list of `Sheet` objects contained in this workbook. If no sheets have been added yet the list is lazily initialized to an empty `ArrayList` and returned.

**Returns:** `java.util.List<Sheet>` — the ordered list of sheets; never `null`.

```java
java.util.List<Sheet> sheets = workbook.getSheets();
```

---

### `getSheet(int index)` *(protected)*

Retrieves the sheet at the specified zero-based position.

<Note>This method is declared `protected`. It is accessible from within the class and its subclasses. Use `getSheets().get(index)` for direct access from external code.</Note>

<ParamField path="index" type="int">
  Zero-based index of the sheet to retrieve.
</ParamField>

**Returns:** `Sheet` — the sheet at the given index.

**Throws:** `ArrayIndexOutOfBoundsException` if `index` is greater than or equal to the number of sheets.

```java
Sheet first = workbook.getSheets().get(0);
```

---

### `getSheet(String name)` *(protected)*

Retrieves a sheet by its name using a case-insensitive comparison.

<Note>This method is declared `protected`. Use `getSheets()` and iterate for external access.</Note>

<ParamField path="name" type="String">
  The name of the sheet to look up. Comparison is case-insensitive.
</ParamField>

**Returns:** `Sheet` — the first sheet whose name matches, or `null` if no match is found.

```java
// From a subclass or internal context:
Sheet summary = getSheet("Summary");
```

---

### `addSheet(Sheet sheet)` *(protected)*

Appends a single sheet to the end of the workbook's sheet list.

<Note>This method is declared `protected`. Use `getSheets().add(sheet)` from external code, or subclass `Workbook` to expose it.</Note>

<ParamField path="sheet" type="Sheet">
  The `Sheet` instance to append.
</ParamField>

**Returns:** `void`

```java
// From a subclass or internal context:
addSheet(new Sheet());
```

---

### `addSheets(java.util.List<Sheet> sheets)` *(protected)*

Appends all sheets from the provided list to the workbook in iteration order.

<Note>This method is declared `protected`. Use `getSheets().addAll(sheets)` from external code.</Note>

<ParamField path="sheets" type="java.util.List<Sheet>">
  A list of `Sheet` instances to append.
</ParamField>

**Returns:** `void`

```java
// From a subclass or internal context:
addSheets(java.util.List.of(sheetA, sheetB));
```

---

### `replaceSheet(Sheet sheet)`

Replaces the first sheet whose name matches the name of the supplied sheet (case-insensitive). If no sheet with a matching name exists the workbook is left unchanged.

<ParamField path="sheet" type="Sheet">
  The replacement `Sheet`. Its `getName()` value is used to identify which existing sheet to overwrite.
</ParamField>

**Returns:** `void`

```java
Sheet updatedSheet = new Sheet();
// updatedSheet must have the same name as the sheet being replaced
workbook.replaceSheet(updatedSheet);
```

---

### `removeSheet(int index)` *(protected)*

Removes the sheet at the specified zero-based index.

<Note>This method is declared `protected`. Use `getSheets().remove(index)` from external code.</Note>

<ParamField path="index" type="int">
  Zero-based index of the sheet to remove.
</ParamField>

**Returns:** `void`

```java
// From a subclass or internal context:
removeSheet(0);
```

---

### `removeSheet(String name)`

Removes the first sheet whose name matches the supplied string (case-insensitive). Does nothing if no match is found.

<ParamField path="name" type="String">
  The name of the sheet to remove. Comparison is case-insensitive.
</ParamField>

**Returns:** `void`

```java
workbook.removeSheet("OldSheet");
```

---

### `size()`

Returns the number of sheets currently in the workbook.

**Returns:** `int` — the sheet count.

```java
int count = workbook.size(); // e.g. 3
```

## JsonMapper

`JsonMapper` is the pre-configured Jackson mapper for Sheet JSON serialization and deserialization. It extends `tools.jackson.databind.json.JsonMapper` and applies these defaults:

- Registers `JsonOrgModule` so `org.json.JSONObject` and `JSONArray` are handled natively.
- Enables `USE_BIG_DECIMAL_FOR_FLOATS` — floating-point JSON numbers deserialize to `BigDecimal`.
- Enables `USE_BIG_INTEGER_FOR_INTS` — integer JSON numbers deserialize to `BigInteger`.
- Disables automatic visibility of getter, is-getter, and setter methods so only `@JsonProperty`-annotated fields are serialized.

```java
import in.org.quicko.sheet.mapper.JsonMapper;
import in.org.quicko.sheet.beans.Workbook;

JsonMapper mapper = new JsonMapper();

// Serialize
String json = mapper.writeValueAsString(workbook);

// Deserialize
Workbook restored = mapper.readValue(json, Workbook.class);
```

## WorkbookUtil

`WorkbookUtil` provides a static utility method to convert a `Workbook` into an Apache POI `XSSFWorkbook` (XLSX format).

### `WorkbookUtil.toExcel(Workbook workbook)`

Converts a `Workbook` object into an `XSSFWorkbook`. Each `Sheet` becomes an XLSX sheet tab. `Table` blocks are rendered with a title row, a header row, and data rows. `List` blocks are rendered as two-column key-value rows.

<ParamField path="workbook" type="Workbook">
  The `Workbook` instance to convert.
</ParamField>

**Returns:** `org.apache.poi.xssf.usermodel.XSSFWorkbook` — the resulting Apache POI workbook.

**Throws:** `java.io.IOException` if an error occurs during conversion.

```java
import in.org.quicko.sheet.utils.WorkbookUtil;
import org.apache.poi.xssf.usermodel.XSSFWorkbook;
import java.io.FileOutputStream;

XSSFWorkbook excelWorkbook = WorkbookUtil.toExcel(workbook);
try (FileOutputStream fos = new FileOutputStream("output.xlsx")) {
    excelWorkbook.write(fos);
}
excelWorkbook.close();
```

## Full example

The following example builds a workbook, serializes it to JSON with `JsonMapper`, and then deserializes it back.

```java
import in.org.quicko.sheet.beans.Workbook;
import in.org.quicko.sheet.beans.Sheet;
import in.org.quicko.sheet.beans.Table;
import in.org.quicko.sheet.mapper.JsonMapper;
import org.json.JSONArray;

public class WorkbookExample {

    public static void main(String[] args) throws Exception {

        // Build the workbook
        Workbook workbook = new Workbook();

        Sheet sheet = new Sheet();

        Table table = new Table();
        table.setHeader(new JSONArray(java.util.List.of("Name", "Age", "City")));
        table.addRow(new JSONArray(java.util.List.of("Alice", 30, "New York")));
        table.addRow(new JSONArray(java.util.List.of("Bob",   25, "London")));

        sheet.addBlock(table);
        workbook.getSheets().add(sheet);

        // Serialize to JSON
        JsonMapper mapper = new JsonMapper();
        String json = mapper.writeValueAsString(workbook);
        System.out.println(json);

        // Deserialize back
        Workbook restored = mapper.readValue(json, Workbook.class);
        System.out.println("Sheet count: " + restored.size());
    }
}
```
