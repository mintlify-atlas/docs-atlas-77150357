---

`Table` is one of the two concrete `Block` subtypes (the other being `List`). It models a classic spreadsheet grid: a single `header` row that names the columns, followed by any number of data rows. Both the header and each data row are `JSONArray` instances, keeping values loosely typed so they can hold strings, numbers, booleans, or `null`. `Table` exposes a column-oriented view through `getColumns()`, which returns an array of `Column` objects — each column has its header as its first element followed by all row values at that position. `Table` extends `Block`, which in turn extends `BaseObject`.

## Import

```typescript
import { Table } from '@org-quicko/sheet';
```

## Constructor

### `new Table()`

Creates a new, empty `Table` with an empty `header` array and an empty `rows` array.

```typescript
const table = new Table();
```

## Instance Methods

### `getHeader()`

Returns the header row for this table.

**Returns:** `JSONArray`

---

### `setHeader(header)`

Replaces the table's header row.

<ParamField path="header" type="JSONArray" required>
  A `JSONArray` whose elements are the column names for this table.
</ParamField>

**Returns:** `void`

---

### `getRows()`

Returns all data rows as a `JSONArray` of `JSONArray` entries. Each inner array corresponds to one data row.

**Returns:** `JSONArray`

---

### `getRow(index)`

Returns a **copy** of the row at the given zero-based index. The copy is constructed as `new JSONArray(...)` from the original row data.

<ParamField path="index" type="number" required>
  Zero-based index of the row to retrieve.
</ParamField>

**Returns:** `JSONArray` — a new `JSONArray` copy of the requested row.

**Throws:** `RangeError` when `index` is equal to or greater than the number of rows.

---

### `addRow(row)`

Appends a single data row to the end of the rows array.

<ParamField path="row" type="JSONArray" required>
  The row to append. Values should correspond positionally to the header columns.
</ParamField>

**Returns:** `void`

---

### `addRows(rows)`

Appends multiple data rows in one call.

<ParamField path="rows" type="JSONArray[]" required>
  An array of `JSONArray` row objects to append.
</ParamField>

**Returns:** `void`

---

### `popRow()`

Removes the last data row from the table. Has no effect if the table is empty. Does not return the removed row.

**Returns:** `void`

---

### `replaceRow(index, row)`

Replaces the row at the given zero-based index with a new row.

<ParamField path="index" type="number" required>
  Zero-based index of the row to replace.
</ParamField>

<ParamField path="row" type="JSONArray" required>
  The replacement row data.
</ParamField>

**Returns:** `void`

---

### `removeRow(index)`

Removes the row at the given zero-based index.

<ParamField path="index" type="number" required>
  Zero-based index of the row to remove.
</ParamField>

**Returns:** `void`

**Throws:** `RangeError` when `index` is equal to or greater than the number of rows.

---

### `getColumns()`

Returns a column-oriented view of the table. Each `Column` in the returned array has the column header as its first element (`this[0]`) and then the corresponding cell value from every row at that column position. The number of `Column` objects equals the number of entries in the header.

**Returns:** `Array<Column>`

---

### `length()`

Returns the number of data rows in the table (the header does not count).

**Returns:** `number`

---

## Inherited from `Block` / `BaseObject`

### `getName()`

Returns the entity name string registered on the class (e.g. `"table"`).

**Returns:** `string`

---

### `getEntity()`

Returns the `@entity` discriminator string (`"table"`).

**Returns:** `string`

---

### `getMetadata()`

Returns the freeform metadata map attached to this table.

**Returns:** `JSONObject`

---

### `setMetadata(value)`

Replaces the metadata map on this table.

<ParamField path="value" type="JSONObject" required>
  The new metadata object.
</ParamField>

**Returns:** `void`

---

## Usage Example

```typescript
import { Table } from '@org-quicko/sheet';
import { JSONArray } from '@org-quicko/core';

const table = new Table();

// Set the header
table.setHeader(new JSONArray(['name', 'department', 'salary']));

// Add rows
table.addRow(new JSONArray(['Alice', 'Engineering', 120_000]));
table.addRow(new JSONArray(['Bob', 'Marketing', 95_000]));
table.addRow(new JSONArray(['Carol', 'Engineering', 130_000]));

console.log(table.length()); // 3

// Read a specific row (returns a copy)
const row = table.getRow(1);
console.log(row); // JSONArray ['Bob', 'Marketing', 95000]

// Column-oriented access
const columns = table.getColumns();
console.log(columns[0].getColumnHeader()); // 'name'
console.log(columns[0]);                   // Column ['name', 'Alice', 'Bob', 'Carol']

// Replace and remove
table.replaceRow(1, new JSONArray(['Bob', 'Sales', 100_000]));
table.removeRow(2);
console.log(table.length()); // 2
```
