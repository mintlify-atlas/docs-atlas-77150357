Sheet Tools is a browser application bundled with the Sheet JSON repository at `frontend/nextjs/org-quicko-sheet-tools`. It provides two interactive tools — the Schema Builder and the Sheet Visualiser — that let you design workbook structures and inspect workbook data without writing any code. Data never leaves your machine; all processing happens in the browser.

## Tech stack

Sheet Tools is built on the following technologies:

| Technology | Role |
|---|---|
| [Next.js 15](https://nextjs.org/) | React framework and file-based routing |
| [React 19](https://react.dev/) | Component model and state management |
| [Tailwind CSS](https://tailwindcss.com/) | Utility-first styling |
| [shadcn/ui](https://ui.shadcn.com/) (Radix UI) | Accessible UI component primitives |
| [Zustand](https://zustand-demo.pmnd.rs/) | Schema builder state store |
| [@tanstack/react-virtual](https://tanstack.com/virtual) | Virtualized table rendering in the visualiser |
| [IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API) | Browser-local persistent storage |

## Run Sheet Tools locally

Sheet Tools is a standard Next.js application managed with `pnpm`. Run the following commands from the repository root to install dependencies and start the development server:

```bash
cd frontend/nextjs/org-quicko-sheet-tools
pnpm install
pnpm dev
```

Open the URL printed by the development server (typically `http://localhost:3000`) to access the Sheet Tools landing page.

## Local storage model

The two tools use different persistence strategies:

- **Schema Builder** — Every workbook schema you create or import is saved to the browser's IndexedDB database under `sheet-tools-db`. Each workbook is stored as a separate record keyed by its name, so changes to one workbook can never overwrite another. The storage layer uses a minimal promise-based wrapper around the native IndexedDB API with no external persistence library. On startup, the Schema Builder migrates any data left by earlier versions that used `localStorage` into IndexedDB automatically.

- **Sheet Visualiser** — Workbook data is held in memory for the current browser session only. It is not persisted to IndexedDB or any other storage. Export your workbook before closing the tab if you want to reload it later.

<Note>
  Schema Builder workbooks are stored in browser IndexedDB only and are not synced to any server or shared across devices. If you clear your browser's site data, all locally saved workbooks will be removed. Export any schemas you want to keep before clearing browser storage. Sheet Visualiser data is session-only and is lost on page reload.
</Note>
