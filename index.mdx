Sheet JSON gives you a consistent, language-independent way to model workbook data — workbooks, sheets, tables, and lists — as plain JSON. Use the TypeScript or Java SDK to read, build, and transform that data in code. Generate typed classes from a JSON Schema so your application accesses sheets and blocks through a strong type system. Convert workbooks to and from `.xlsx` files with a single method call.

## How it works

<Steps>
  <Step title="Model your workbook as JSON">
    Define a workbook with one or more sheets. Each sheet holds Table blocks (header + rows) or List blocks (key-value pairs). All entities carry an `@entity` discriminator and a `name`.
  </Step>
  <Step title="Install the SDK for your language">
    Add `@org-quicko/sheet` (npm) or `in.org.quicko.sheet:core` (Maven) to your project. Both ship typed classes that serialize to and from the Sheet JSON format.
  </Step>
  <Step title="Generate typed classes from JSON Schema">
    Write a JSON Schema that describes your workbook's sheets and blocks. Run the generator to produce language-specific classes. Application code imports those classes to access data with full type safety.
  </Step>
  <Step title="Import and export XLSX">
    Call `Workbook.fromXlsx(buffer)` to parse an existing spreadsheet file. Call `Workbook.toXlsx(workbook)` to write one back out. The converter handles table and list layout automatically.
  </Step>
</Steps>
